# 🎓 منصة استعراض نتائج التلاميذ الرقمية

مرحباً بك حضرة المدير. هذه المنصة مصممة لتسهيل عملية وصول التلاميذ لنتائجهم السنوية بكل سهولة ويسر عبر البحث بالاسم أو الرقم.

## 📁 هيكلية ملف النتائج (results.xlsx)
لكي تعمل المنصة بشكل صحيح، يرجى التأكد من أن ملف الإكسل المرفوع يحتوي على الأعمدة التالية وبنفس الترتيب والأسماء:

1.  **الرقم** (رقم التلميذ الخاص)
2.  **الاسم** (الاسم الكامل)
3.  **اللغة العربية**
4.  **التربية الاسلامية**
5.  **الرياضيات**
6.  **الفرنسية**
7.  **العلوم**
8.  **التاريخ والجغرافيا**
9.  **التربية المدنية**
10. **التربية الفنية**
11. **الرياضة**
12. **المجموع**
13. **المعدل**
14. **الرتبة**
15. **القرار** (يجب أن يحتوي على كلمة "ناجح" أو "راسب")

---

## 🚀 كيفية تحديث النتائج
في كل مرة تريد فيها تحديث نقاط التلاميذ، اتبع الخطوات التالية:
1. قم بتجهيز ملف الإكسل على جهازك وتسميته بـ `results.xlsx`.
2. ادخل إلى مستودع المشروع (Repository) على **GitHub**.
3. قم برفع الملف (Upload) واستبدال النسخة القديمة.
4. سيقوم الموقع بتحديث البيانات تلقائياً للتلاميذ.

---

## 🛠️ المتطلبات التقنية
لتشغيل المنصة محلياً، يجب تثبيت المكتبات اللازمة عبر الأمر:
```bash
pip install -r requirements.txt
```
